# API按量余额查询工具
可以快速查询你在各大网站的按量余额，也可以小挂件的方式显示。

ps.后续应该会添加各种形式的显示，如按次，计时等

也可以自己用ai工具添加不同站点及余额获取方式

点展示键就会变成可爱鲸鱼娘，自动置顶、可变大小、点击刷新。
